# Roteiro Completo do Workshop IA como Serviço

# Da habilidade ao cliente

Este roteiro organiza os momentos criados para transformar o conteúdo base em uma experiência prática de workshop.

---

# Sequência dos momentos

## 1. Da Ferramenta ao Serviço Vendável

Arquivo:

```text
primeiro-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Frase de oferta:
Eu ajudo [cliente] a resolver [problema] usando IA para gerar [resultado].
```

## 2. Escolhendo o Serviço de IA

Arquivo:

```text
segundo-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Categoria de serviço, primeira entrega e possibilidade de recorrência.
```

## 3. Montando a Escada de Serviços

Arquivo:

```text
terceiro-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Oferta de entrada -> Projeto inicial -> Projeto estratégico -> Mensalidade
```

## 4. Diagnóstico Empresarial com o Método MAPA INEMA

Arquivo:

```text
quarto-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Roteiro de diagnóstico por nicho.
```

## 5. Transformando Diagnóstico em Proposta Comercial

Arquivo:

```text
quinto-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Proposta comercial resumida.
```

## 6. Precificação de Serviços de IA

Arquivo:

```text
sexto-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Preços de entrada, projeto inicial, projeto estratégico e mensalidade.
```

## 7. Construção de Proposta ao Vivo

Arquivo:

```text
setimo-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Proposta completa construída a partir de um caso prático.
```

## 8. Conseguindo os Primeiros Clientes

Arquivo:

```text
oitavo-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Canais de prospecção, lista inicial e mensagem de abordagem.
```

## 9. Pitch, Abordagem e Lista de Clientes

Arquivo:

```text
nono-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Pitch de 30 segundos, mensagens e lista de 20 potenciais clientes.
```

## 10. Kit Prestador de Serviços IA

Arquivo:

```text
decimo-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Kit comercial consolidado e plano de ação de 7 dias.
```

## 11. Sistema Operacional do Prestador de Serviços de IA

Arquivo:

```text
decimo-primeiro-momento-workshop-ia-como-servico.md
```

Entrega:

```text
Rotina, templates, indicadores e próximos passos pós-workshop.
```

- Momento 7: Construção de proposta ao vivo

# Entrega final do workshop

Ao final da experiência completa, cada participante deverá ter:

```text
1. Nicho escolhido
2. Problema principal
3. Oferta principal
4. Oferta de entrada
5. Projeto inicial
6. Projeto estratégico
7. Serviço recorrente
8. Preços
9. Roteiro de diagnóstico
10. Proposta comercial
11. Pitch de 30 segundos
12. Lista de 20 potenciais clientes
13. Mensagem de abordagem
14. Plano de ação de 7 dias
15. Sistema operacional mínimo
```
