# Identidade Visual - Workshop IA como Serviço

# INEMA.PRO

## Nome do projeto

**IA como Serviço**

## Assinatura

**Da habilidade ao cliente**

## Promessa visual

Transformar conhecimento técnico em oferta vendável.

A identidade deve comunicar:

- clareza;
- execução;
- método;
- negócio;
- aplicação prática;
- maturidade profissional.

Não deve parecer uma aula genérica sobre IA, nem uma promessa futurista abstrata.

Deve parecer um workshop para quem quer transformar IA em serviço, proposta, cliente e recorrência.

---

# Referência INEMA.PRO observada

Com base nos projetos locais do INEMA.PRO, a linguagem visual atual usa:

- fundo escuro quase preto;
- tipografia grande, limpa e direta;
- títulos com alto contraste;
- acento ciano como cor principal;
- uso pontual de roxo, verde, amarelo e vermelho como acentos;
- cards discretos com borda fina;
- elementos de interface;
- linhas, grades, orbitas e estruturas técnicas;
- composição centralizada;
- pouco ruído visual;
- copy curta e assertiva.

Para o workshop, a identidade mantém essa base, mas adiciona um acento mais comercial usando **âmbar** para representar venda, proposta e dinheiro.

---

# Conceito visual

## Ideia central

**Da ferramenta ao contrato.**

O participante sai de um ponto técnico:

```text
ferramenta
```

e atravessa uma sequência comercial:

```text
problema -> oferta -> diagnóstico -> proposta -> preço -> cliente -> recorrência
```

## Metáforas visuais

Use principalmente:

- mapa;
- escada;
- fluxo;
- radar;
- interface;
- diagnóstico;
- proposta;
- pipeline;
- contrato;
- recorrência.

Evite:

- cérebro futurista genérico;
- robôs humanoides;
- excesso de brilho;
- visual infantil;
- estética de criptomoeda;
- imagens abstratas sem relação com serviço.

## Regra de uso

O ciano é a cor principal.

O âmbar deve aparecer quando o conteúdo falar de:

- cliente;
- venda;
- proposta;
- preço;
- recorrência;
- contrato;
- negócio.

O verde deve aparecer quando o conteúdo falar de:

- operação;
- processo;
- automação;
- melhoria;
- manutenção.

O roxo deve aparecer quando o conteúdo falar de:

- método;
- trilha;
- estratégia;
- transição de mentalidade.

O vermelho/rosa deve ser usado apenas para:

- problema;
- risco;
- erro comum;
- perda.

# Sistema gráfico

## Elemento principal

**Radar de oportunidade**

Um conjunto de linhas elípticas ou grade técnica representando:

- diagnóstico;
- leitura de cenário;
- mapeamento;
- descoberta de oportunidade.

## Elemento secundário

**Escada de serviços**

Representa:

```text
Entrada -> Projeto -> Estratégico -> Recorrência
```

Pode aparecer como:

- degraus;
- cards conectados;
- pipeline horizontal;
- lista vertical numerada.

## Elemento terciário

**Fluxo comercial**

Representa:

```text
Problema -> Oferta -> Proposta -> Cliente
```

Pode aparecer em slides de método e exercícios.

# Direção para peças

## Capa principal

Visual:

- fundo carbon black;
- radar ciano no topo/centro;
- título grande central;
- acento âmbar discreto em "Serviço";
- chips: Oferta, Diagnóstico, Proposta, Recorrência.

## Slide de método

Visual:

- quatro cards horizontais;
- cada card com uma letra ou número;
- linha conectando as etapas;
- ciano para estrutura;
- âmbar para etapa comercial.

## Slide de exercício

Visual:

- fundo escuro;
- área central em card;
- campos com bordas finas;
- rodapé com entrega esperada.

## Post de divulgação

Visual:

- frase forte;
- sem excesso de texto;
- CTA curto;
- contraste alto.

# Regras práticas

## Fazer

- usar poucas palavras por slide;
- manter contraste alto;
- deixar respiro;
- usar ciano como estrutura;
- usar âmbar para venda/negócio;
- usar cards discretos;
- repetir padrões entre peças;
- destacar uma ideia por tela.

## Evitar

- muitos efeitos;
- muitas cores no mesmo slide;
- ilustrações genéricas de IA;
- texto longo em capa;
- estética infantil;
- excesso de gradiente;
- promessa exagerada;
- linguagem técnica demais.
