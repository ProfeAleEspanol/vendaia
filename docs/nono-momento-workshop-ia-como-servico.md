# Nono Momento do Workshop

# Pitch, Abordagem e Lista de Clientes

## Objetivo

Fazer cada participante transformar sua oferta em uma fala comercial curta, clara e aplicável em conversas reais.

Ao final deste momento, cada participante deverá ter:

- pitch de 30 segundos;
- versão curta para WhatsApp;
- versão para apresentação presencial;
- resposta para objeções comuns;
- lista de 20 potenciais clientes.

---

# Duração sugerida

**75 minutos**

## Divisão do tempo

- 10 min: retomada da prospecção
- 20 min: construção do pitch
- 15 min: mensagens de abordagem
- 15 min: objeções
- 15 min: lista dos 20 clientes

---

# 1. Retomada

## Fala do facilitador

No momento anterior, vimos onde encontrar os primeiros clientes.

Agora precisamos deixar a fala comercial simples.

Se alguém perguntar:

> O que você faz?

O participante precisa responder sem explicar ferramenta, sem dar aula e sem parecer genérico.

O objetivo do pitch não é fechar a venda na hora.

O objetivo é abrir uma boa conversa.

---

# 2. Fórmula do pitch

Use esta estrutura:

```text
Eu ajudo [tipo de cliente]
a resolver [problema]
usando IA para gerar [resultado].

Normalmente começo com [oferta de entrada]
para identificar oportunidades e propor o primeiro projeto.
```

## Exemplo

```text
Eu ajudo clínicas odontológicas a reduzir mensagens perdidas no WhatsApp usando IA para melhorar o atendimento e aumentar agendamentos.

Normalmente começo com um diagnóstico do atendimento para identificar onde existe demora, retrabalho ou oportunidade de automação.
```

---

# 3. Pitch de 30 segundos

## Estrutura completa

```text
1. Quem eu ajudo
2. Qual problema resolvo
3. Qual resultado busco gerar
4. Como começo
5. Convite para conversa
```

## Modelo

```text
Eu ajudo [cliente] a resolver [problema] usando IA para gerar [resultado].

Tenho olhado principalmente para processos de [área], onde normalmente aparecem tarefas repetitivas, demora ou perda de oportunidades.

O primeiro passo costuma ser um diagnóstico rápido para mapear onde IA pode gerar resultado com menor complexidade.

Se fizer sentido, podemos conversar por 20 minutos para identificar oportunidades no seu processo.
```

---

# 4. Exemplos de pitch

## Clínicas

```text
Eu ajudo clínicas a reduzir o trabalho manual no WhatsApp usando IA para responder dúvidas frequentes, organizar triagem e melhorar o aproveitamento de agendamentos.

Normalmente começo com um diagnóstico do atendimento para mapear onde existem mensagens repetidas, demora e oportunidades de automação.
```

## Imobiliárias

```text
Eu ajudo imobiliárias a responder e acompanhar leads mais rápido usando IA para reduzir oportunidades perdidas.

O primeiro passo é um diagnóstico do fluxo comercial, desde a entrada do lead até o follow-up.
```

## Escritórios contábeis

```text
Eu ajudo escritórios contábeis a organizar documentos e dúvidas internas usando IA para reduzir retrabalho e dependência de pessoas específicas.

Começo com um diagnóstico dos processos e informações mais consultadas pela equipe.
```

## Agências

```text
Eu ajudo agências e profissionais de marketing a estruturar uma operação de conteúdo com IA para produzir mais com menos esforço manual.

O primeiro passo é mapear o fluxo atual de criação, aprovação e publicação.
```

# 5. Versão curta para WhatsApp

## Modelo

```text
Oi, [nome]. Trabalho ajudando [tipo de cliente] a resolver [problema] usando IA.

Estou oferecendo um diagnóstico rápido para identificar oportunidades de automação em [área].

Faz sentido conversarmos por 20 minutos esta semana?
```

## Exemplo

```text
Oi, Carlos. Trabalho ajudando imobiliárias a responder e acompanhar leads mais rápido usando IA.

Estou oferecendo um diagnóstico rápido para identificar oportunidades de automação no atendimento comercial.

Faz sentido conversarmos por 20 minutos esta semana?
```

# 6. Respostas para objeções

## Objeção: "Não tenho tempo agora."

```text
Entendo. A ideia é justamente fazer uma conversa curta, de 20 minutos, para identificar se existe algo que esteja consumindo tempo da equipe e poderia ser simplificado.
```

## Objeção: "Já usamos ChatGPT."

```text
Ótimo. O diagnóstico não é sobre usar ou não uma ferramenta específica. É sobre entender onde a IA pode entrar no processo da empresa para reduzir retrabalho, demora ou perda de oportunidades.
```

## Objeção: "Isso deve ser caro."

```text
Pode variar bastante. Por isso eu começo pelo diagnóstico. Antes de falar em projeto, precisamos entender se existe uma oportunidade real e qual seria a primeira entrega viável.
```

## Objeção: "Minha equipe não vai usar."

```text
Esse é um ponto importante. Uma boa implantação precisa considerar o jeito que a equipe já trabalha. O diagnóstico ajuda justamente a encontrar uma solução simples o suficiente para ser adotada.
```

## Objeção: "Não sei se isso serve para minha empresa."

```text
É exatamente o tipo de coisa que o diagnóstico responde. Pode ser que exista uma oportunidade clara, ou pode ser que ainda não seja o momento. A conversa serve para descobrir isso.
```

# 9. Simulação rápida

## Dinâmica

Em trios:

- uma pessoa apresenta o pitch;
- uma pessoa faz o papel do cliente;
- uma pessoa observa.

O observador avalia:

- ficou claro quem é o cliente?
- ficou claro qual problema é resolvido?
- ficou claro qual resultado é buscado?
- o convite para diagnóstico foi natural?
- o pitch ficou curto?

Depois, trocam os papéis.

---

# 10. Fechamento

## Fala do facilitador

Um bom pitch não precisa explicar tudo.

Ele precisa gerar interesse suficiente para uma próxima conversa.

Se o cliente entendeu quem você ajuda, que problema você resolve e qual é o primeiro passo, o pitch cumpriu sua função.

No próximo momento, vamos consolidar todo o material no Kit Prestador de Serviços IA.
