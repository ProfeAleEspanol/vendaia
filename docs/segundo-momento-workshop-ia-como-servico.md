# Segundo Momento do Workshop

# Escolhendo o Serviço de IA

## Objetivo

Transformar a primeira frase de oferta criada no momento anterior em um tipo claro de serviço.

Ao final deste momento, cada participante deverá saber em qual categoria sua oferta se encaixa e qual pode ser sua primeira versão comercial.

---

# Duração sugerida

**75 minutos**

## Divisão do tempo

- 10 min: retomada do primeiro momento
- 20 min: apresentação do Cardápio INEMA de Serviços de IA
- 15 min: exemplos práticos por tipo de serviço
- 20 min: exercício de escolha da oferta
- 10 min: compartilhamento e refinamento

---

# 1. Retomada

## Fala do facilitador

No primeiro momento, cada participante criou uma frase de oferta:

```text
Eu ajudo [tipo de cliente] a resolver [problema] usando IA para gerar [resultado].
```

Agora vamos dar o próximo passo.

Uma frase de oferta ainda é uma hipótese.

Para virar serviço, ela precisa entrar em uma categoria mais clara:

- diagnóstico;
- atendimento;
- comercial;
- processos internos;
- base de conhecimento;
- conteúdo;
- implantação para equipes;
- ferramenta interna.

O objetivo agora é responder:

> Que tipo de serviço eu posso vender primeiro?

---

# 2. Ideia central

## Fala do facilitador

Muita gente trava porque pensa que precisa criar algo totalmente novo.

Na prática, a maioria dos serviços de IA para empresas entra em algumas categorias recorrentes.

O segredo não é inventar uma oferta completamente diferente.

O segredo é escolher uma categoria, aplicar em um nicho e resolver um problema real.

Por exemplo:

```text
Categoria: atendimento
Nicho: clínicas odontológicas
Problema: WhatsApp sobrecarregado
Oferta: Assistente Inteligente de Atendimento para Clínicas
```

```text
Categoria: base de conhecimento
Nicho: escritórios de contabilidade
Problema: dificuldade para encontrar informações internas
Oferta: Base de Conhecimento Inteligente para Equipes Contábeis
```

```text
Categoria: conteúdo
Nicho: profissionais liberais
Problema: falta de frequência nas redes sociais
Oferta: Operação de Conteúdo com IA para Autoridades Locais
```

# 3. Cardápio INEMA de Serviços de IA

## 1. Diagnóstico de IA

Serviço de entrada para identificar oportunidades de uso de IA dentro de uma empresa.

### Quando vender

- o cliente ainda não sabe onde usar IA;
- a empresa tem muitos processos manuais;
- existe interesse, mas falta clareza;
- o participante ainda não tem confiança para vender uma implantação maior.

### Entrega principal

> Mapa de Oportunidades de IA.

### Nome comercial possível

> Diagnóstico de Oportunidades de IA para Empresas.

---

## 2. Assistente Inteligente de Atendimento

Serviço voltado para melhorar o atendimento em canais como WhatsApp, site, Instagram, Telegram ou suporte interno.

### Problemas que resolve

- muitas perguntas repetidas;
- demora no retorno;
- mensagens esquecidas;
- equipe sobrecarregada;
- atendimento fora do horário comercial;
- dificuldade para fazer triagem.

### Nichos possíveis

- clínicas;
- imobiliárias;
- escolas;
- restaurantes;
- lojas;
- prestadores de serviço;
- consultórios.

### Nome comercial possível

> Assistente Inteligente de Atendimento para [nicho].

---

## 3. Assistente Comercial com IA

Serviço voltado para captação, qualificação e acompanhamento de leads.

### Problemas que resolve

- leads sem resposta;
- falta de follow-up;
- perda de oportunidades;
- atendimento comercial lento;
- dificuldade para organizar contatos;
- baixa conversão de interessados em reuniões.

### Nichos possíveis

- imobiliárias;
- escolas;
- clínicas;
- agências;
- consultorias;
- empresas B2B;
- infoprodutores.

### Nome comercial possível

> Assistente Comercial com IA para [nicho].

---

## 4. Automação de Processos Internos

Serviço voltado para reduzir trabalho manual em tarefas administrativas e operacionais.

### Problemas que resolve

- copiar e colar informações;
- preencher planilhas manualmente;
- organizar documentos;
- enviar avisos repetitivos;
- criar relatórios;
- atualizar sistemas;
- classificar solicitações.

### Áreas possíveis

- financeiro;
- RH;
- compras;
- administrativo;
- operações;
- suporte;
- atendimento.

### Nome comercial possível

> Automação Inteligente de Processos para [área ou nicho].

---

## 5. Base de Conhecimento Inteligente

Serviço voltado para organizar documentos, procedimentos e informações internas.

### Problemas que resolve

- dificuldade para encontrar informações;
- conhecimento concentrado em poucas pessoas;
- dúvidas internas repetidas;
- documentos espalhados;
- demora para treinar novos colaboradores;
- falta de padronização.

### Materiais que podem entrar

- manuais;
- contratos;
- políticas;
- procedimentos;
- FAQs;
- treinamentos;
- documentos comerciais;
- informações de produtos.

### Nome comercial possível

> Base de Conhecimento Inteligente para [nicho ou equipe].

---

## 6. Operação de Conteúdo com IA

Serviço voltado para produção, adaptação e organização de conteúdo.

### Problemas que resolve

- falta de frequência de publicação;
- dificuldade para criar roteiros;
- reaproveitamento ruim de conteúdos;
- equipe pequena de marketing;
- demora para produzir posts, vídeos e legendas;
- falta de processo editorial.

### Entregas possíveis

- roteiros;
- posts;
- carrosséis;
- cortes;
- legendas;
- newsletters;
- vídeos com avatar;
- calendário editorial.

### Nome comercial possível

> Operação de Conteúdo com IA para [nicho].

---

## 7. Implantação de IA para Equipes

Serviço voltado para ensinar, organizar e implementar o uso prático de IA dentro de uma equipe.

### Problemas que resolve

- equipe usa IA de forma desorganizada;
- cada pessoa cria seus próprios prompts;
- falta padrão de uso;
- ferramentas são usadas sem processo;
- liderança quer produtividade, mas não sabe por onde começar.

### Entregas possíveis

- treinamento;
- biblioteca de prompts;
- escolha de ferramentas;
- processos internos;
- guias de uso;
- acompanhamento;
- templates de trabalho.

### Nome comercial possível

> Implantação de IA na Equipe [comercial, atendimento, marketing ou administrativa].

---

## 8. Ferramentas Internas com Vibe Code

Serviço voltado para criar ferramentas simples e úteis para resolver problemas operacionais.

### Problemas que resolve

- controle manual em planilhas;
- ausência de painel gerencial;
- processos sem sistema;
- dificuldade para gerar propostas;
- organização ruim de clientes;
- falta de visualização de dados.

### Exemplos

- CRM simples;
- gerador de propostas;
- dashboard;
- painel comercial;
- portal interno;
- sistema de orçamento;
- controle de clientes;
- ferramenta administrativa.

### Nome comercial possível

> Ferramenta Interna Inteligente para [problema específico].

# 4. Como escolher a primeira oferta

## Critérios

O participante não deve escolher apenas o serviço mais interessante tecnicamente.

Ele deve escolher o serviço com maior chance de virar venda.

Use estes critérios:

- Tenho capacidade de entregar uma primeira versão?
- Conheço alguém que poderia comprar isso?
- O problema é comum nesse tipo de cliente?
- O resultado é fácil de explicar?
- A implantação pode ser pequena no começo?
- O serviço pode gerar manutenção ou recorrência depois?

## Regra prática

Para começar, a melhor oferta costuma ter três características:

- problema fácil de entender;
- cliente fácil de acessar;
- primeira entrega simples.

# 5. Exercício

## Instrução

Cada participante deve pegar a frase criada no primeiro momento e preencher o mapa abaixo.

## Mapa de escolha do serviço

```text
1. Minha frase de oferta:

2. Qual problema principal essa oferta resolve?

3. Essa oferta se encaixa melhor em qual categoria?
   [ ] Diagnóstico de IA
   [ ] Atendimento
   [ ] Comercial
   [ ] Processos internos
   [ ] Base de conhecimento
   [ ] Conteúdo
   [ ] Implantação para equipes
   [ ] Ferramenta interna

4. Quem seria o primeiro tipo de cliente ideal?

5. Que entrega simples eu poderia fazer primeiro?

6. Como essa entrega poderia evoluir para um projeto maior?

7. Como essa entrega poderia gerar uma mensalidade?

8. Nome inicial da minha oferta:
```

---

# 6. Exemplo preenchido

```text
1. Minha frase de oferta:
Eu ajudo clínicas odontológicas a reduzir mensagens perdidas no WhatsApp usando IA para melhorar o atendimento e aumentar agendamentos.

2. Problema principal:
Recepção sobrecarregada e demora para responder pacientes.

3. Categoria:
Atendimento.

4. Primeiro tipo de cliente ideal:
Clínicas odontológicas com alto volume de mensagens no WhatsApp.

5. Entrega simples:
Diagnóstico do atendimento atual + organização das principais perguntas e respostas + protótipo de assistente de atendimento.

6. Evolução para projeto maior:
Implantação completa do assistente, integração com agenda e acompanhamento de leads.

7. Possível mensalidade:
Monitoramento, ajustes das respostas, novas automações, relatórios e suporte.

8. Nome inicial da oferta:
Assistente Inteligente de Atendimento para Clínicas Odontológicas.
```

# 7. Compartilhamento

## Dinâmica

Escolha alguns participantes para apresentarem:

- frase de oferta;
- categoria escolhida;
- primeiro cliente ideal;
- primeira entrega simples.

## Perguntas para o grupo

- A categoria escolhida faz sentido?
- A primeira entrega está simples demais, complexa demais ou adequada?
- O cliente entenderia o valor dessa oferta?
- Existe uma forma clara de evoluir para projeto maior?
- Existe possibilidade de recorrência?

# 8. Fechamento do segundo momento

## Fala do facilitador

Agora cada participante não tem apenas uma ideia.

Tem uma hipótese de serviço.

Essa hipótese precisa ter:

- cliente;
- problema;
- categoria;
- primeira entrega;
- possibilidade de evolução;
- possibilidade de recorrência.

Esse é o começo da escada de serviços.

No próximo momento, vamos organizar essa escada:

```text
Oferta de entrada -> Projeto inicial -> Projeto estratégico -> Mensalidade
```

O objetivo será transformar a oferta escolhida em uma estrutura comercial que possa ser vendida com começo, meio, fim e continuidade.

- um nicho ou tipo de cliente inicial;
- uma primeira entrega simples;
- uma ideia de evolução para projeto maior;
- uma possibilidade de serviço recorrente;
- um nome inicial para sua oferta.
